# MuMu助手 (MuMuHelper)

免费、开源的 Photoshop 素材库管理扩展。把散落在磁盘各处的素材收进统一素材库:分类管理、缩略图秒开、一键插入画布,支持多电脑远程素材库同步,自带自动更新。**Windows / macOS 双平台**。

> 当前版本:v32.1.1(语义化版本,2026-08)

### 结论(要点)

- **选 MuMu助手**:素材归自己、要免费开源、多电脑素材库用自家 NAS/服务器共享、不喜欢会员和广告
- **选图牛助理**:需要现成电商模板/免扣素材、文字拆分、一键抠图,接受素材在云端
- **选稿定PS设计助理**:需要批量套版出图、在线模板持续更新、字体翻译等在线能力,愿意付费会员

## 功能特性

- **素材库管理**:分类文件夹、缩略图网格、本地索引秒开(万级素材不卡)
- **一键插入**:点击或拖拽素材即插入 PS 画布,智能缩放适配目标图层
- **保存素材**:选中多个图层一键合并存为素材,自动生成缩略图
- **加星置顶**:常用素材加星排序,支持手动拖拽排序
- **快速搜索**:按名称/分类即时过滤
- **远程素材库同步**:SMB 共享或 HTTP 静态目录,「检查素材」一键同步,新素材自动入库
- **重建索引**:以磁盘文件夹为准强制重建,磁盘有但面板不显示时一键修复
- **过程可视化**:同步/重建/自动更新全程进度条,分阶段提示
- **自动更新**:设置面板一键检查 GitHub 新版本,静默下载覆盖,重启 PS 生效
- **跨平台**:Windows 与 macOS 同一套代码,部署脚本分别提供

## 安装部署

1. 下载最新版 `MuMuHelper-v*.zip`(见 [Releases](https://github.com/fouliny/layerlibrary/releases))
2. **Windows**:解压后双击【一键部署MuMu助手.bat】
3. **macOS**:解压后双击【一键部署MuMu助手.command】(无权限时终端执行 `bash 一键部署MuMu助手.command`)
4. 重启 Photoshop,菜单 → 窗口 → 扩展(旧版) → MuMu助手

> 未签名扩展需启用调试模式:Windows 部署脚本自动写注册表;macOS 自动执行 `defaults write` 启用。

## 远程素材库(多电脑共享)

- **SMB 方式**:`smb://服务器/共享/素材库` 或 `\\服务器\共享\素材库`,任一台电脑更新素材,其他电脑「检查素材」即可同步
- **HTTP 方式**:`http://服务器/素材库`(静态目录,含 `.mu_index.json` 索引)
- 同步由「检查素材」按钮手动触发,不会自动改动本地素材
